# Engineering Decisions

> Purpose: 定义长期项目级工程决策的记录范围与格式。

## Scope

本目录只记录对未来工程实践有长期影响的重要项目级决策。只有用户明确确认，或已由项目实践验证的长期工程选择，才适合形成正式 Decision 文档。

本目录不用于记录：

- 普通技术知识
- 聊天过程
- 临时 Debug 决策
- 尚未获得用户确认的 AI 建议

AI 建议可以作为待确认事项讨论，但不能直接写成正式决策。当前不为尚未确认或没有长期影响的事项创建 Decision 文件。

## Recommended Template

```markdown
# Decision: <title>

Date:
Status: Confirmed

## Context

## Decision

## Reason

## Consequences
```
